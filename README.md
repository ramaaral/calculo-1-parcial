## Activar Pages (una sola vez)

GitHub no deja que el workflow cree el sitio solo. Entrá acá:

1. https://github.com/ramaaral/calculo-1-parcial/settings/pages
2. **Source** → **GitHub Actions**
3. Guardá.
4. Andá a Actions y dale **Re-run** al workflow *Deploy GitHub Pages*.

En el celular: menú del navegador → **Agregar a inicio** / **Instalar app**.
